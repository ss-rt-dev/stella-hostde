Deine Vorteile bei uns

Unsere Qualitätsmerkmale im Überblick.

Echte NVMe Hardware

Wir setzen konsequent auf Enterprise NVMe SSDs und moderne Prozessoren. Kein geteilter Flaschenhals, maximale I/O-Leistung für deine Projekte.

Kein Overselling

Was du buchst, gehört dir. Ressourcen werden auf unseren Nodes fest zugewiesen, sodass dein Server auch bei Volllast absolut flüssig läuft.

Permanent DDoS-Schutz

Unser filterbasierter Schutzverbund fängt böswilligen Traffic ab, noch bevor er deinen Gameserver oder Webspace einschränken kann.

Volle Flexibilität

Keine versteckten Verträge. Verwalte deine Setups unkompliziert per Ticket und passe Ressourcen flexibel an, wenn deine Community wächst.

Häufig gestellte Fragen

Alles, was du vor dem Start wissen musst.

Wie funktioniert die Bestellung per Ticket-ID?

+
Unser System generiert nach dem Konfigurieren eine verschlüsselte ID (z.B. ST-MC-211-AZ). Diese postest du einfach in unserem Discord-Support. Ein Teammitglied liest die ID direkt aus, sodass dein Server exakt nach Wunsch manuell und fehlerfrei bereitgestellt wird.

Gibt es versteckte Vertragslaufzeiten?

+
Nein, bei Stella Host setzen wir auf absolute Transparenz. Alle Server laufen auf Prepaid-Basis oder mit monatlich kündbaren Intervallen. Lädst du dein Guthaben nicht auf oder kündigst im Ticket, läuft der Server einfach aus.

Welche Zahlungsmethoden werden akzeptiert?

+
Wir akzeptieren alle gängigen Zahlungsmethoden wie PayPal, Paysafecard und Krypto-Zahlungen. Die Abrechnung erfolgt unkompliziert direkt während der Ticketeröffnung.

Was passiert bei einem DDoS-Angriff?

+
Unser Schutzsystem läuft permanent im Hintergrund. Sobald schadhafter Traffic erkannt wird, schalten sich unsere automatischen Filterregeln live davor. Dein Server bleibt online und die Spieler merken im Idealfall absolut nichts davon.
